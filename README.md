# NetworkScaleLabel

Android-приложение для работы с сетевыми весами и печати этикеток.

## Описание

Мобильное приложение для подключения к сетевым весам, получения данных о массе товара и печати этикеток через принтер.

## Текущая реализация (v1.1)

- Подключение к сетевым весам **ШТРИХ-ПРИНТ** по Ethernet/UDP (порт по умолчанию 1111, пароль 0030)
- Чтение состояния весов (команда 0x11): версия ПО, размер таблицы товаров, НПВ и т.д.
- Полное чтение базы товаров (ПЛУ) из весов с прогрессом и отменой:
  расширенным форматом 0x58 с автоматическим фолбэком на базовый 0x51
- Отображение товаров на устройстве: список с поиском (по наименованию/коду/№ ПЛУ),
  карточки с ценой и типом товара (весовой/штучный), диалог с полными данными ПЛУ
- **Диагностика сети**: строка «Сеть телефона» с IP и подсетью, предупреждение,
  если весы в другой подсети (типичная причина ошибки подключения)
- **Понятные ошибки вместо «connect -1»**: нет маршрута / порт закрыт / таймаут —
  с подсказками, что проверить
- **Поиск весов**: UDP-сканирование подсети телефона (broadcast + юникаст пробы 0x11
  без пароля) — найденные весы можно подставить в поле IP одним нажатием
- Протокол: «Протокол обмена весов ШТРИХ-ПРИНТ v1.6», строки CP1251, цены в МДЕ

### Если «Ошибка connect -1» / весы не подключаются

Эта ошибка означает, что ядро Android не смогло даже направить UDP-пакеты
на адрес весов — **телефон и весы в разных подсетях**, между ними нет маршрута.
Что проверить:

1. Откройте настройки Wi-Fi телефона и посмотрите свой IP. Если он не из сети
   весов (например, телефон 192.168.1.x, а весы 192.168.140.89) — подключитесь
   к той Wi-Fi-сети, за которой стоит сеть весов (или настройте маршрут на роутере).
2. Убедитесь, что Wi-Fi раздаёт тот же роутер, в чей LAN включены весы
   (или точка доступа в режиме моста/bridge, а не «роутер за роутером»).
3. На точке доступа должна быть отключена изоляция клиентов (AP/Client Isolation).
4. Нажмите «Найти весы» в приложении — оно проверит подсеть телефона и покажет,
   отвечает ли кто-то на UDP 1111.

## Технологии

- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Архитектура:** MVVM + Clean Architecture
- **DI:** Hilt
- **Асинхронность:** Kotlin Coroutines + Flow
- **Сеть:** Retrofit + OkHttp
- **БД:** Room

## Требования

- Android Studio Ladybug или новее
- JDK 21+
- Android SDK 37
- Min SDK: 26 (Android 8.0)

## Сборка

```bash
./gradlew assembleDebug
```

APK будет located в: `app/build/outputs/apk/debug/`
